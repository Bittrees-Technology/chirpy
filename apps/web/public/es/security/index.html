Informar de una vulnerabilidad de Chirpy

Utiliza los informes privados de vulnerabilidades de GitHub para enviar un hallazgo de seguridad a los responsables del repositorio de Chirpy.

Iniciar un informe de seguridad privado

Se requiere una cuenta de GitHub. Los informes se gestionan mediante el proceso privado de avisos de seguridad del repositorio; no publiques detalles de explotación en incidencias públicas mientras se evalúa un informe.

Detalles útiles para el informe

  • La versión o revisión afectada y la función implicada.
  • El comportamiento esperado y observado, con una reproducción mínima utilizando cuentas de prueba.
  • El impacto potencial y si existe una solución provisional.

No incluyas mensajes privados de usuarios reales, credenciales activas, frases de recuperación, claves privadas ni firmas de cartera. Utiliza datos de prueba. No realices pruebas en cuentas ajenas ni cambies la pertenencia a salas de producción para demostrar un problema.

La versión preliminar web pública y la rama principal actual son las versiones de desarrollo mantenidas. Todavía no hay una versión nativa estable publicada ni un plazo de corrección garantizado.
