Ayuda de Chirpy

Chirpy está actualmente en versión preliminar pública. Para informar de errores o pedir ayuda con la aplicación, utiliza el sistema de incidencias del proyecto en GitHub.

Informar de un error o pedir ayuda

Qué incluir

Describe lo que ocurrió, lo que esperabas, la versión de tu navegador o aplicación y los pasos para reproducir el problema. Elimina la información personal de las capturas de pantalla y los registros.

Nunca incluyas frases de recuperación, claves privadas, firmas de cartera, tokens de autenticación ni el contenido de mensajes privados.

Problemas frecuentes

  • Salas restringidas no disponibles: la organización necesita un servicio externo de control de acceso configurado y un registro de salas publicado. Contacta con el administrador de tu organización.
  • Conflicto de sincronización: conserva el borrador local, recarga la aplicación y vuelve a intentar la sincronización. Los clientes antiguos deben recargarse antes de guardar.
  • Mensajería abierta en otra pestaña: cierra la otra pestaña de Chirpy y vuelve a intentarlo.

Estado actual de preparación para producción (en inglés)

Las posibles vulnerabilidades deben enviarse mediante informes de seguridad privados, no en incidencias públicas. Esta versión preliminar no ofrece un plazo de respuesta garantizado para las solicitudes de ayuda.
