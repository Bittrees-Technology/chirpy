Chirpy support

Chirpy is currently a public preview. For bugs and help using the app, use the project's GitHub issue tracker.

Report a bug or request help

What to include

Describe what happened, what you expected, your browser or app version, and steps that reproduce the issue. Remove personal information from screenshots and logs.

Never include seed phrases, private keys, wallet signatures, authentication tokens, or private message contents.

Common issues

  • Gated rooms unavailable: the organization needs a configured external gatekeeper and a published room registry. Contact your organization administrator.
  • Sync conflict: keep the local draft, refresh the app, and retry sync. Older clients must refresh before saving.
  • Messaging open in another tab: close the other Chirpy tab and retry.

Current production-readiness status

Suspected vulnerabilities belong in private security reports, not public issues. No guaranteed support response time is offered for this preview.
