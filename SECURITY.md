# Security reporting

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/Bittrees-Technology/chirpy/security/advisories/new). Reports go to the repository maintainers in GitHub's private advisory workflow. A GitHub account is required.

Include the affected commit/version, a minimal reproduction using test identities and synthetic data, impact, and any workaround. Do not include seed phrases, private keys, authentication tokens, wallet signatures, or private message contents. Do not test other people's accounts or alter production room membership.

The current main branch and public web preview are maintained development surfaces. No stable native release is published yet. No response-time or remediation SLA is currently offered; check report updates in GitHub.

Use the [public issue tracker](https://github.com/Bittrees-Technology/chirpy/issues) for ordinary bugs or support. Keep exploit details private while a vulnerability report is assessed. This reporting channel does not constitute a security audit or production-readiness certification.
